# 👟 Thala 7 Sneaker Store

**"Thala For a Reason!"** 🏏

Thala 7 Sneaker Store is a stylish, responsive sneaker shopping website inspired by the legendary number 7. It provides a simple online shopping experience where users can explore sneakers, select sizes, add products to their cart, apply discount coupons, and try a demo checkout.

## ✨ Features

* **Modern Homepage:** Attractive design with a sneaker-themed hero section.
* **Sneaker Gallery:** View different sneaker images.
* **Size Selection:** Choose your preferred shoe size.
* **Shopping Cart:** Add sneakers, view quantities, and remove items.
* **Price Summary:** Automatically calculates subtotal, tax, discount, and total.
* **Coupon System:** Apply the `THALA10` coupon code to receive a 10% discount.
* **Checkout Page:** Enter customer details and select a demo payment method.
* **Responsive Design:** Designed to work on desktop and mobile screens.
* **Interactive Elements:** JavaScript adds functionality to the shopping experience.

## 🛠️ Technologies Used

* **HTML5** – Website structure.
* **CSS3** – Styling and responsive layout.
* **JavaScript** – Interactive features and shopping cart calculations.
* **Unsplash** – Sneaker images.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Install the **Live Server** extension in VS Code if you haven't already.
5. Right-click `index.html`.
6. Select **Open with Live**
